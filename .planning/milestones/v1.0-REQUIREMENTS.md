## V1 Requirements (All Validated)

### Virtual Filesystem & Structural SII Engine

- [x] **VFS-01** *(Validated — Phase 1)*: Read HashFS v1/v2 archives, standard `.scs`/`.zip` packages, and unpacked mod directories across Windows and Linux paths cleanly, while safely detecting and reporting `3nK`-obfuscated or `AEM!`/encrypted ZIP archives without attempting to crack them.
- [x] **VFS-02** *(Validated — Phase 1)*: Extract ETS2 `1.62.3.3s` baseline metadata from `def.scs` and `locale.scs` (36 Vanilla+DLC country definitions, `speed_limits.sii`, `sign/board/*.sii`, and all 43 active locales) into deterministic schemas/fixtures under `data/baselines/ets2_1.62_def/`.
- [x] **SII-01** *(Validated — Phase 1)*: Parse and surgically edit ETS2 `.sii`/`.sui` country files and `speed_limits.sii` while preserving comments, formatting, `regions[]`, `secondary_time_zone_area[]`, `secondary_time_zone[]`, `train`, `tram`, and unrelated attributes untouched.
- [x] **SII-02** *(Validated — Phase 1)*: Enforce strict SCS SII serialization hygiene on every generated file: UTF-8 without BOM, LF (`\n`) line endings, POSIX `/` internal paths, valid unit scoping, and idempotent round-trip output.

### Realism Registry, Seasonal Builds & Offline Validator (Phase A)

- [x] **SIM-01** *(Validated — Phase 2)*: Maintain a canonical ISO country/territory realism registry (`data/laws/`, `data/mappings/`) supporting `Summer` and `Winter` speed-limit and DRL policies while fixing all known bugs from reference mods (`3249064596`, `3668352310`).
- [x] **SIM-02** *(Validated — Phase 2)*: Compute accurate seasonal UTC offsets and abbreviations dynamically from stdlib `zoneinfo` + `tzdata`, emitting valid ETS2 integer minutes and plain strings (e.g., `"CET"`, `"WET"`) while respecting ETS2's 12 supported `@@tz_*@@` keys.
- [x] **SIM-03** *(Validated — Phase 2)*: Package dual **Vanilla+DLC Core** mods (`Summer` and `Winter`) covering all 36 SCS countries with complete Workshop metadata (`manifest.sii`, description, `276x162` `.jpg` mod icon) built purely from open-source repository assets.
- [x] **PUB-01** *(Validated — Phase 2)*: Run an Offline SCS Workshop Validator covering SCS validation error checks `00001`–`00010` and warnings `WARN 00001`/`00002` (encoding, icon dimensions/JPEG format, manifest integrity, unit/board references) before releasing any artifact.
- [x] **PUB-02** *(Validated — Phase 2)*: Gate releases via a canonical SHA-256 hash ledger (`state/published.json`) comparing normalized package content against previously published state to prevent empty/no-op uploads and emit clean diffs.
- [x] **PUB-03** *(Validated — Phase 2)*: Provide a Phase A Semi-Auto GitHub Actions CI & release workflow (scheduled Fridays aligned with the EC Weekly Oil Bulletin release plus manual dispatch) outputting validated `Summer` and `Winter` bundles, markdown changelogs, and `realism-snapshot-{summer|winter}.json` without storing Steam secrets.

### Open European Fuel/FX Pipeline & Zero-DDS Totem Engine

- [x] **DAT-01** *(Validated — Phase 3)*: Fetch and cross-validate FX exchange rates using `Frankfurter v2` (`MIT`, 219 currencies), `ECB` validator, `fawazahmed0` currency API (`CC0`), and `CBR` FX with deterministic country-currency mapping and currency-split sanity checks.
- [x] **DAT-02** *(Validated — Phase 3)*: Collect Tier 1 open European & EEA government fuel data from `EC Weekly Oil Bulletin` (dynamic XLSX discovery + `FionnHughes`/`fuel-prices.eu` fallback), `UK DESNZ`, `NO SSB`, and multi-grade national APIs (`FR`, `DE`, `ES`, `IT`, `NL`).
- [x] **DAT-03** *(Validated — Phase 3)*: Enforce circuit-breaker safety (`0.01–5.00 EUR/L` equivalent bounds and `±25%` change alerts) backed by `prices.lock.json` so stale or broken upstream endpoints safely fall back to last-known-good attributed values.

## Overview

**ETS2 Country Realism** (`ets2-country-realism` / package `ets2_realism` / CLI `ets2-realism`, maintained by **MissionWAR**) is an open-source (`MIT` code / `CC BY 4.0` curated data), clean-room Python `3.12+` (`uv`) pipeline, mod compiler, and local map-combo composer for **Euro Truck Simulator 2 `1.62.3.3s`+**.

Across five cohesive V1 phases, the project builds a pure-Python HashFS/SII foundation, validates seasonal Vanilla+DLC Core Workshop editions (`Summer` & `Winter`) under Phase A semi-auto CI, wires legally clean European fuel/FX feeds into a 43-locale Zero-DDS totem system, extends realism safely to ProMods (`EU + ME + MA + TGS`) and arbitrary user map combos via `ets2-realism compose-local`, and scales to `225` global territories with an isolated OSM drift audit. Full-auto SteamCMD Workshop publishing (`PUB-V2-01`, `PUB-V2-02`) is deferred to a future V2 milestone.

## Key Accomplishments

1. **Clean-Room VFS & Structural SII Engine (Phase 1):** Built a pure-Python HashFS v1/v2 (`CityHash64` MIT + `zlib`), ZIP, and unpacked VFS overlay with safe `3nK`/`AEM!`/encrypted-ZIP detection (zero cracking), deterministic ETS2 `1.62.3.3s` `def.scs`/`locale.scs` baseline extraction (`36` countries, `43` locales, `460` fuel boards), and a comment/region-preserving surgical SII/SUI rewriter enforcing UTF-8 no-BOM LF hygiene.
2. **Canonical Realism Registry, Seasonal Core Builds & Offline SCS Validator (Phase 2):** Authored clean-room seasonal laws + dynamic `zoneinfo`/`tzdata` DST calculation (honoring ETS2's 12 `@@tz_*@@` keys), compiled dual `Summer` & `Winter` Vanilla+DLC Core mods (`276x162` RGB JPEG icons, `mp_mod_optional: true`), built an Offline SCS Workshop Validator (`00001`–`00010`, `WARN 00001`/`00002`), and wired SHA-256 diff-gated Friday `06:00 UTC` Phase A CI releases (`state/published.json`).
3. **Open European Fuel/FX Pipeline & Option 4b Zero-DDS Totems (Phase 3):** Integrated multi-provider FX cross-validation (`Frankfurter v2`, `ECB`, `fawazahmed0`, `CBR`) and Tier 1 EU/EEA government fuel feeds (`EC Weekly Oil Bulletin`, `UK DESNZ`, `NO SSB`, `FR`/`DE`/`ES`/`IT`/`NL`) with `prices.lock.json` circuit breakers (`0.01–5.00 EUR/L`, `±25%` WoW alerts), compiling all `460` `1.62` fuel sign boards into namespaced `@@fp_*_ets2r@@` tokens synchronized across all `43` active locales with zero `.dds`/`.tobj` textures.
4. **ProMods Companion Builder & Local Map Combo Composer (Phase 4):** Shipped versioned `realism-snapshot-{summer|winter}.json` (`schema_version=1`) + `SHA256SUMS.txt` rolling release contracts, a local ProMods Companion Builder (`EU + ME + MA + TGS` with zero ProMods files tracked in Git), and `ets2-realism compose-local` with `FieldOwnershipPolicy` (`max_of_map_and_real` axles, `patch_if_single_tz`, `119` map aliases, `AEM!`/`3nK` diagnostics + `--unpacked-defs`, opt-in `--patch-hardcoded-totems`).
5. **Global 225-Territory Coverage & Quarantined OSM Audit (Phase 5):** Scaled snapshots to `225` countries/territories (`151` currencies) via `8` non-EU Tier 1 government APIs, `10` fault-isolated Tier 2 national portals, and `186` Tier 3 curated baselines, paired with an AST-quarantined internal monthly OSM speed-limit drift audit (`CC BY-SA` strictly isolated from `CC BY 4.0` outputs via `ETS2R-INV-LICENSE-TAINT`).
6. **Public Release Polish & Brand Finalization:** Rebranded cleanly to `ETS2 Country Realism` (`ets2_realism` / `ets2-realism` by `MissionWAR`), hardened external-CWD output guards, CH BFS PxWeb POST queries, CI `--previous-snapshots-dir` structured changelog diffs, dynamic `anchor_year`, root `README.md`/`LICENSE`, and `5/5` Nyquist validation docs.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Raw `.sii`/`.sui` Bytes (Game or Third-Party Mods) -> `ets2v2.sii` | Arbitrary text encodings, malformed braces, `..` paths, or oversized token segments enter parser |
| Serialized `.sii`/`.sui` Output -> ETS2 Engine / Workshop Uploader | Emitted files must satisfy strict UTF-8 no-BOM, LF, `@include` column-0, and token rules |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-10 | Tampering | `hygiene.py` (`normalize_sii_bytes`, `validate_sii_hygiene`) | medium | mitigate | Strictly decode UTF-8 (strip BOM only, fail with `SiiEncodingError` on malformed bytes rather than silent latin1 fallback), reject `\\` and `..` paths, reject non-column-0 `@include`, and enforce `[a-z0-9_]{1,12}` unit segments |
| T-01-11 | Tampering | `document.py`, `country.py`, `speed_limits.py` | high | mitigate | Use structural token/span replacement instead of global regex string substitution so Estonia `"Eesti"` corruption, `regions[]` deletion, and `train`/`tram` clobbering cannot occur |
| T-01-12 | Denial of Service | `lexer.py`, `sign_board.py` | low | mitigate | Single-pass O(n) linear scanner with explicit bounds on `/* */` comment closing and `items: N` matching so malformed SII inputs raise clean parse diagnostics without quadratic backtracking or infinite loops |
| T-01-16 | Tampering | SII/SUI runtime dependencies (`01-04`) | high | mitigate | No package-manager installs in `01-04`; uses stdlib (`struct`, `re`, `dataclasses`) and locked `pydantic 2.14.3` verified in `01-RESEARCH.md` and `uv.lock` |
</threat_model>

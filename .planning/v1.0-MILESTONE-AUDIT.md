## 5. Non-Blocking Tech Debt, Edge-Case Bugs & Operational Readiness

### A. Verified Runtime Edge-Case Bugs (Low/Medium Impact, Workarounds Exist)

1. **`assert_out_dir_not_tracked()` falsely rejects valid external-CWD output directories (`src/ets2_realism/merge/promods_builder.py:82-110`)**
   - `_candidate_repo_roots()` unconditionally appends `Path.cwd().resolve()` even when CWD is not a Git repository. Running `ets2-realism compose-local --out-dir ./mod` from `D:\ETS2Data\Euro Truck Simulator 2` raises `ValueError: Refusing to write ProMods/Combo output inside tracked/unignored repository directory`.
   - **Fix:** Only append `cwd` to `_candidate_repo_roots()` when `(cwd / ".git").exists()` or `(cwd / "pyproject.toml").is_file()`.
2. **`fetch_ch_bfs_lik()` sends HTTP `GET` to a PxWeb v1 `.px` endpoint expecting `POST` (`src/ets2_realism/fetch/tier2_portals.py:632-668`)**
   - PxWeb `.px` URLs return schema metadata JSON on `GET`, which will trip `Tier2SelectorDriftError` on live runs and fall back to `fuel_prices_eu` / `state/prices.lock.json` (isolated by `_run_tier2_guarded()`, so Core CI never breaks).
   - **Fix:** Send a `POST` PxWeb query payload (like `fetch_no_ssb_09654()`) or switch to a direct BFS CSV download URL.
3. **`phase-a-release.yml` never wires `--previous-snapshots-dir` (`.github/workflows/phase-a-release.yml:151-161`, `src/ets2_realism/cli.py:603`)**
   - Every CI run currently renders static initial-release highlights instead of `## Changes Since Previous Snapshot` diffs. In addition, `cli.py:603` reads `--previous-snapshots-dir` via unbounded `read_text("utf-8")` instead of `load_realism_snapshot()`.
   - **Fix:** Add a best-effort `gh release download snapshots-latest` step into a temp dir before `publish release` and route `cli.py:603` through `load_realism_snapshot()`.

Works cleanly in editable repo checkouts (`uv run`), but fails under `pip install` / `uv tool install`.
